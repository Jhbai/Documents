# 採樣率過低
當採樣率過低，所建立動態預測模型(LSTM MPC)會失效，因此必須藉由統計學的大數法則，將操作動作的離散 0/1 訊號透過 sliding windows 轉化為機率意義上的「等效開通率」，藉此抓出系統的穩態增益(開多少閥會影響多少目標變數)。

量化當前系統的震盪極限，作為未來評估高採樣率控制效能的 Baseline

## 特徵工程：等效開通率 (Duty Cycle) 轉換
不要把 0/1 當作絕對的開關狀態，而是將其視為伯努利分佈的樣本。對 0/1 序列套用滾動視窗（Sliding Window，例如 $W=10$ 到 $15$ 分鐘）計算平均值。

這個均值在統計上能逼近該區段內系統動作的真實開通率

滑動視窗涵蓋了過去一段時間，但我們永遠把算出來的等效開通率，標記在視窗的**「最右邊界（當下最新時間點）」**。這代表「從過去到現在這 $W$ 分鐘內，我們總共累積了多少開通量」

## 尋找純延遲時間 (Delay Alignment)
化學反應有管路與混合延遲。假設透過分析發現系統的反應延遲（Dead Time）為 3 分鐘。這代表 $t=10$ 累積的開通率，要到 $t=13$ 才會真正在 Sensor 上反應

在資料表中，我們會把計算好的等效開通率整行「往未來平移（Shift） 3 格」

計算 開通率 與 $\Delta$目標變數的交叉相關（Cross-Correlation），找出相關係數絕對值最大的時間滯後（Lag）步數

## 系統穩態增益 (Steady-State Gain) 估計
將算出的酸閥與鹼閥「等效開通率」作為特徵（$X$），將「目標變數」作為目標變數（$y$），繪製散佈圖並擬合線性迴歸模型，這能初步確立機台的化學反應增益（例如：開通率每增加 10%，目標變數 會在 5 分鐘後上升多少）

## 極限環與震盪能力 (Limit Cycle & Volatility) 量化
以目標 Setpoint 為基準，計算目標變數歷史資料的均方根誤差(RMSE)、標準差與震盪分佈區間（Histogram/KDE）

因為目前的控制帶有化學遲滯與 0/1 操作的非線性，系統必然會在 Setpoint 上下產生持續的週期震盪（極限環）

精確量化這個震盪幅度，才能證明未來導入秒級 MPC 後，究竟收斂了多少誤差

# 數學表示
設低採樣率動作觀測值為 $v_k \in \{0, 1\}$，滾動視窗大小為 $W$。等效開通率 $D_k$ 的特徵提取公式為：

$$D_k = \frac{1}{W} \sum_{i=k-W+1}^k v_i$$

建立多變數線性迴歸模型來估計穩態增益：

$$\Delta y_k = y_k - y_{k-1} = \beta_{actionA} \times D_{actionA, k-d} + \beta_{actionB} \times D_{actionB, k-d} $$

# 導入高採樣率資料後後對於 MPC 誤差收斂
衡量 "系統純延遲時間內的隨機雜訊"，先算出目前系統的總誤差變異數，利用數學模型推算出該物理系統在存在延遲下的「理論最小變異數（絕對極限）」。

兩者相減的差額，就是未來導入高採樣率 MPC 後，能夠榨出來的「可收斂誤差空間」

## 計算當下變異數
直接計算歷史資料中，實際目標變數值偏離目標值（Setpoint）的均方誤差或變異數。這代表了當下 0/1 控制與環境干擾共同造成的總震盪幅度

## 估計理論最小變異數 (MVC Benchmark)
利用時間序列分析（如 ARMA 模型）對現有目標變數數據進行擬合，分離出系統的「白雜訊（無法預測的隨機擾動）」。

因為化學反應有純延遲（Dead Time，假設為 $d$ 步），在控制器下達指令到系統真正反應的這 $d$ 步之內，任何控制器都對這段期間發生的白雜訊無能為力。

這 $d$ 步內的白雜訊累積量，就是理論上的「最小變異數（Minimum Variance）」。

## 計算可壓縮空間 (Harris Index)
將目前的變異數減去理論最小變異數，這個差值就是由於 0/1 閥門非線性、PID 參數不佳所導致的「額外震盪」。

這部分就是未來高採樣率 MPC 可以徹底消滅的誤差空間

# 數學表示

根據沃爾德分解定理（Wold's Decomposition），任何穩態時間序列都可以拆解為無限多個白雜訊的線性組合。

系統的總誤差等於「純延遲內的雜訊誤差（不可控）」加上「純延遲外的控制誤差（可控）」。最佳控制器（如理想 MPC）能將「可控」部分的誤差降為零，只留下「不可控」的物理極限
