## 第二部分：核心考點分類

### 1. Two Pointers（雙指針）

**概念與直觀解釋：**
在排序陣列中，使用兩個指針從兩端向中間移動，根據比較結果動態調整指針位置。類似於在街上相向而行的兩個人，根據目標位置調整各自的步伐。

**應用場景：**
- 在排序陣列中尋找一對滿足條件的元素
- 移除重複元素或無效元素
- 反轉陣列或鏈表
- 容器盛水問題

**數學分析：**
- 時間複雜度：O(n)，每個指針最多遍歷一次陣列
- 空間複雜度：O(1)，只使用常數額外空間
- 前提條件：通常要求陣列已排序或具有單調性

**高頻題目：**
- 11. Container With Most Water
- 15. 3Sum
- 18. 4Sum
- 42. Trapping Rain Water
- 76. Minimum Window Substring

---

### 2. Sliding Window（滑動窗口）

**概念與直觀解釋：**
在陣列或字符串上維護一個"窗口"，通過擴展和收縮窗口來找到滿足條件的最優子陣列或子串。類似於在錄像帶上滑動一個固定大小的播放頭，實時監控窗口內的內容。

**應用場景：**
- 找滿足條件的最小/最大子陣列
- 字符串中的子串匹配
- 無重複字符的最長子串

**考點深度：**
根據 503. Circular Array 的例子：
- 考 Monotonic Stack 外加 circular 就是 2 倍記憶體的概念
- 但可以透過 idx % n 去模擬，避免額外記憶體

**高頻題目：**
- 3. Longest Substring Without Repeating Characters
- 30. Substring with Concatenation of All Words
- 209. Minimum Size Subarray Sum
- 239. Sliding Window Maximum
- 424. Longest Repeating Character Replacement

---

### 3. DFS / BFS（深度優先搜索 / 廣度優先搜索）

**概念與直觀解釋：**
- **DFS**：深度優先，就像在迷宮中一直往深處走，直到死路為止再回退
- **BFS**：廣度優先，像在池塘中丟石子，波紋一層層向外擴散

**應用場景：**
- 樹和圖的遍歷與搜索
- 連通性檢查（Number of Islands）
- 最短路徑（BFS）
- 拓撲排序（DFS）
- 環檢測

**高頻題目：**
- 94. Binary Tree Inorder Traversal
- 102. Binary Tree Level Order Traversal
- 200. Number of Islands
- 207. Course Schedule
- 236. Lowest Common Ancestor of a Binary Tree

---

### 4. Dynamic Programming（動態規劃）

**概念與直觀解釋：**
大問題分解為許多小問題，保存小問題的答案（記憶化），避免重複計算。就像爬樓梯時記住之前的計數，而不是每次都從頭開始。

**應用場景：**
- 最優化問題（最小路徑、最大值）
- 計數問題
- 決策問題

**核心要素：**
1. 無後效性：當前狀態只取決於之前的狀態
2. 重疊子問題：相同子問題出現多次
3. 最優子結構：全局最優由局部最優組成

**高頻題目：**
- 5. Longest Palindromic Substring
- 62. Unique Paths
- 72. Edit Distance
- 139. Word Break
- 198. House Robber

---

### 5. Monotonic Stack（單調棧）

**概念與直觀解釋：**
棧中的元素保持遞增或遞減順序。就像在售票窗口排隊，每進來一個新人都要檢查他是否比前面的人高，如果是就把前面的人記錄下來（找到他們的下一個更高的人）並讓他們離隊。

**考點示例：**
503. Circular Array → 考 Monotonic Stack 外加 circular 的 2 倍記憶體概念，但可以透過 idx % n 模擬

**應用場景：**
- 找下一個更大/小的元素
- 處理循環陣列問題
- 計算子陣列的貢獻

**高頻題目：**
- 42. Trapping Rain Water
- 84. Largest Rectangle in Histogram
- 239. Sliding Window Maximum
- 503. Next Greater Element II
- 739. Daily Temperatures

---

### 6. Binary Search（二分查找）

**概念與直觀解釋：**
在有序資料中不斷將查找範圍縮小一半，快速定位目標。就像在字典中查找一個詞，打開中間頁面，根據字母順序決定向前翻還是向後翻。

**應用場景：**
- 在排序陣列中查找元素
- 查找邊界（第一個 >= target，最後一個 <= target）
- 二分查找答案（Guess 一個值，檢驗是否可行）

**高頻題目：**
- 33. Search in Rotated Sorted Array
- 34. Find First and Last Position of Element in Sorted Array
- 74. Search a 2D Matrix
- 153. Find Minimum in Rotated Sorted Array
- 875. Koko Eating Bananas

---

### 7. Hash Map / Hash Set（哈希表）

**概念與直觀解釋：**
使用哈希函數將鍵映射到值，支持 O(1) 的查找、插入、刪除。就像一個魔法字典，通過名字可以瞬間找到對應的人。

**應用場景：**
- 計數問題（頻率統計）
- 尋找重複或缺失元素
- 快速查找和去重

**高頻題目：**
- 1. Two Sum
- 49. Group Anagrams
- 128. Longest Consecutive Sequence
- 347. Top K Frequent Elements
- 560. Subarray Sum Equals K

---

### 8. Stack（棧）

**概念與直觀解釋：**
LIFO（後進先出）資料結構。就像一堆盤子，最後放上去的盤子最先被拿下來。

**應用場景：**
- 括號匹配
- 表達式計算
- 後綴表達式求值
- 維護遞增/遞減序列

**高頻題目：**
- 20. Valid Parentheses
- 71. Simplify Path
- 155. Min Stack
- 394. Decode String
- 636. Exclusive Time of Functions

---

### 9. Heap / Priority Queue（堆 / 優先隊列）

**概念與直觀解釋：**
完全二叉樹，支持快速獲取最大或最小元素。就像一個排隊系統，每次都能快速找出優先級最高的任務。

**應用場景：**
- Top K 問題
- 中位數計算
- 任務調度

**高頻題目：**
- 215. Kth Largest Element in an Array
- 295. Find Median from Data Stream
- 347. Top K Frequent Elements
- 621. Task Scheduler
- 973. K Closest Points to Origin

---

### 10. Union Find（並查集）

**概念與直觀解釋：**
維護一組集合，支持高效的組合和查詢。就像在社交網絡中標記哪些人是一個朋友圈。

**核心操作：**
1. Find：查詢元素所屬的集合
2. Union：合併兩個集合

**優化技巧：**
- 路徑壓縮（Path Compression）
- 按秩合併（Union by Rank）

**應用場景：**
- 判斷圖的連通性
- 環檢測（尤其是無向圖）
- 動態連通性問題
- 最小生成樹 (Kruskal)

**高頻題目：**
- 200. Number of Islands
- 261. Graph Valid Tree
- 323. Number of Connected Components in an Undirected Graph
- 684. Redundant Connection
- 721. Accounts Merge

---

### 11. Trie（字典樹）

**概念與直觀解釋：**
樹形結構，用於快速查找字符串前綴。就像自動完成功能，輸入前幾個字符就能快速找到所有匹配的詞。

**應用場景：**
- 自動完成功能
- 拼寫檢查
- IP 路由尋址

**高頻題目：**
- 208. Implement Trie (Prefix Tree)
- 211. Design Add and Search Words Data Structure
- 720. Longest Word in Dictionary
- 1268. Search Suggestions System

---

### 12. Bit Manipulation（位運算）

**概念與直觀解釋：**
直接對二進制位進行操作，高效解決某些問題。就像用一根釘子敲兩個目標，一次操作完成兩個任務。

**應用場景：**
- 檢查 2 的冪、奇偶數
- XOR 操作去重
- 位掩碼 DP

**高頻題目：**
- 136. Single Number
- 191. Number of 1 Bits
- 231. Power of Two
- 268. Missing Number
- 421. Maximum XOR of Two Numbers in an Array

## 第三部分：複合考點與進階應用

### 1. Sliding Window + Monotonic Stack

**典型應用：** 解決"滑動窗口中的最大/最小值"問題

**經典題：** 239. Sliding Window Maximum
- 使用 Deque 維護遞減序列
- 新元素進入：刪除隊尾所有 < 新元素的元素
- 窗口移出左邊界：檢查隊首是否已過期

### 2. DFS + Backtracking

**典型應用：** 組合、排列、子集問題

**經典題：**
- 46. Permutations：每層決策是選哪個未用的元素
- 51. N-Queens：每行放一個皇后，檢查列和對角線衝突

### 3. Binary Search + DP

**典型應用：** 某些優化問題

**經典題：** 410. Split Array Largest Sum - 二分答案，驗證是否可行

### 4. Union Find + MST

**典型應用：** Kruskal 演算法求最小生成樹

**經典題：** 1584. Min Cost to Connect All Points
